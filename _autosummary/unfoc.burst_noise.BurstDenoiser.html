unfoc.BurstDenoiser

class BurstDenoiser(median_size: Tuple[int, int], burst_widths: List[float], detect_thresholds: List[float])

Bases: object

Class-encapsulated interface to burst denoising

Applies matched filtering and median filtering to detect and suppress burst noise artifacts in real-valued radar traces.

Parameters:

  • median_size (tuple[int,int]) – Size of the 2D median filter (slow time, fast time). Only 1D filters in slow time are currently supported.

  • burst_widths (list[float]) – Widths of expected burst pulses (in fast-time samples).

  • detect_thresholds (list[float]) – Detection thresholds (in dB) for each pulse width.
