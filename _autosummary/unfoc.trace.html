Container class for pairing radar trace data with control metadata.

Defines the Trace object, which encapsulates a single-channel trace along with its associated data array and control tuple.

class Trace(channel, data, ct)

Bases: object

Pairs channel + data and CT metadata for a trace.

Stores either raw or complex amplitude data along with associated channel number and control tuple (ct) for time/depth/sequence indexing.

Parameters:

  • channel (int) – Channel number associated with this trace.

  • data (np.ndarray) – Trace data array; can be raw amplitudes or complex values.

  • ct (tuple or list of tuples) – Control metadata.

channel, data, ct

Same as parameters; stored without modification.
