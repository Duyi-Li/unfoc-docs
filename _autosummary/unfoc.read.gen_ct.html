unfoc.gen_ct

gen_ct(bxdsfile, full=False)

Generate ct data from the ct file associated with bxdsfile

By default, we only return relevant information. We actually only want the seq and ct tim. If full is True, then return all fields.

Parameters:

bxdsfile (str) – The path to the bxds file for which we want to read the ct file.

Yields:

CT_t or CT_full_t – If full is False, yields CT_t with seq and tim. If full is True, yields CT_full_t with all fields.
