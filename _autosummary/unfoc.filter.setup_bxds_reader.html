unfoc.setup_bxds_reader

setup_bxds_reader(bxdsfile, channel_specs, buffering: int)

Set up the generators for reading from a bxds file and producing pairwise-summed traces or individual unsummed traces

Parameters:

  • bxdsfile (str) – Path to bxds file.

  • channel_specs (PIK1ChannelSpec) – Channel config including burstnoise and scaling.

  • buffering (int) – Buffer size for reading traces.

Returns:

Generator yielding Trace objects.

Return type:

generator
