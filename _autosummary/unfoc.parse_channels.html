unfoc.parse_channels

parse_channels(chanstr)

Parse a legacy-style channel specification into a list of PIK1ChannelSpec objects.

Notes

Supported formats are:

  1. An integer channel number (deprecated).

  2. A MATLAB-style semicolon-separated list of 5-column values, e.g.::

    “[1,1,1,0,0; 2,2,1,0,0]”.

Parameters:

chanstr (int or str) – Integer channel number or formatted string defining multiple channels.

Returns:

Parsed list of channel specifications.

Return type:

list of PIK1ChannelSpec

Raises:

ValueError – If the string format is invalid (wrong number of values).
