unfoc.stack_coherent_chunk

stack_coherent_chunk(coherent_chunk_gen, ct_type='mid', dtype=<class 'numpy.float64'>)

Coherent stacking of a chunk of traces

Stack a chunk of traces coherently and return a Trace object, the number of records, and metadata from the input traces

ct_type can be any of ‘mid’ or ‘all’

Parameters:

  • coherent_chunk_gen (iterable of Trace) – Input traces to stack.

  • ct_type ({'mid', 'all'}, optional) – How to assign the output CT. Default is ‘mid’.

  • dtype (dtype, optional) – Output array data type. Default is float64.

Returns:

(stacked array, number of records, list of cts)

Return type:

tuple
