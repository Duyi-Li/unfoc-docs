unfoc Module

read

Provides functions and objects for reading UTIG radar data formats into numpy.

write

Handler for writing unfoc output files: unfocused radar data products in the UTIG PIK1 format.

dechirp

Math related to dechirping, local oscillator noise suppression and frequency domain filtering.

filter

Filtering operations for unfocused processing

trace

Container class for pairing radar trace data with control metadata.

parse_channels(chanstr)

Parse a legacy-style channel specification into a list of PIK1ChannelSpec objects.

Main body for burst noise filtering
